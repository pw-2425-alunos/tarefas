# Tarefas

API para gestão de tarefas.

* API Tarefas: [documentação](https://tarefas.pw.deisi.ulusofona.pt/docs)
* Webapp: [aceder a uma webapp que consome da API](https://tarefas.pw.deisi.ulusofona.pt/web/)
* Frontend: código-fonte da webapp
* Download: Frontend ZIP

## Executar o frontend

Descarregar a pasta frontend, abrir o index.html no VS Code e executar com a extensão Live Server.

O frontend comunica com a API online.

## Tecnologias

Django · HTML · CSS · JavaScript · Fetch API · Lucide
